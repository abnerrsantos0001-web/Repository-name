# 10 fórmulas de gancho para o Instagram (edição 2026)

Cada superfície tem seu gancho:

- **Legenda:** os primeiros ~125 caracteres, antes do "mais".
- **Slide 1 do carrossel:** a pessoa decide em menos de um segundo se vai arrastar.
- **Reels:** os primeiros 1 a 3 segundos (imagem + texto na tela + primeira fala).

Cada fórmula tem um objetivo principal, ligado aos sinais que o Instagram mais valoriza em 2026:

| Objetivo | O que gera | Por que importa |
|---|---|---|
| **salvamentos** | "vou voltar nisso" | sinal mais forte de conteúdo de referência |
| **compartilhamentos** | envios por direct e para o story | sinal mais forte de alcance em 2026 |
| **comentários** | conversa no post | indica que vale a pena mostrar o post |
| **seguidores** | visita ao perfil que vira follow | sinal de crescimento |

IG1 a IG4 são fórmulas de **legenda**, IG5 a IG8 de **carrossel**, IG9 e IG10 de **Reels**.
Os exemplos abaixo são modelos para a Ramos Corp: os `{campos}` só podem ser preenchidos com dados reais do usuário.

---

## IG1: Resultado em número (legenda) · salvamentos

```
{resultado em número} em {período}.

o que mudamos na conta está aqui embaixo.
```

Exemplo de forma: `uma conta de autopeças saiu de {X} para {Y} visitas por semana em {N} dias.`

**Por quê:** um número "quebrado" (47, 212) parece medição real e promete um método repetível.
**Cuidado:** nunca invente o número.

## IG2: Verdade contrária (legenda) · compartilhamentos

```
{conselho que todo vendedor repete} está errado.

{o que funciona, dito sem rodeio.}
```

Exemplo de forma: `baixar o preço não é o primeiro passo quando as vendas param no Mercado Livre.`

**Por quê:** uma opinião "printável" é enviada para amigos. **Cuidado:** só publique o que você defende nos comentários.

## IG3: Cena que todo mundo reconhece (legenda) · comentários

```
{uma linha que joga o leitor numa situação que todo vendedor do ML conhece.}
```

Exemplo de forma: `abrir o painel do Mercado Livre segunda de manhã e ver o termômetro amarelo por causa de 2 atrasos.`

**Por quê:** reconhecimento imediato, os comentários enchem de "eu". **Cuidado:** o detalhe específico é o que faz funcionar.

## IG4: Mini-história verdadeira (legenda) · comentários e seguidores

```
{marcador de tempo}: {o que aconteceu, incluindo a parte ruim}.

{a única linha de aprendizado que justifica a leitura.}
```

**Cuidado:** tem que ser verdade. Vulnerabilidade fabricada é percebida e punida.

## IG5: Lista em carrossel · salvamentos

```
Slide 1: {N} {coisas} que {ganho específico}. (quase todo mundo erra a {k})
Slides 2..N-1: um item por slide, com exemplo concreto.
Último slide: resumo em uma linha + "salva para usar quando for revisar seus anúncios".
```

## IG6: Antes e depois · salvamentos e seguidores

```
Slide 1: {o depois, com número ou imagem marcante}.
Slide 2: onde começou (o antes).
Slides 3..N-1: os passos exatos, um por slide.
Último slide: "segue para ver o método completo de {tema}" + pedido de salvar.
```

**Cuidado:** passos vagos ("seja consistente") matam o salvamento. Só use com caso real e autorizado pelo cliente.

## IG7: Derrubando mitos · compartilhamentos

```
Slide 1: {N} mitos sobre {tema} que estão custando {perda específica}.
Slides 2..N-1: "Mito: {crença}." / "Verdade: {o que funciona}."
Último slide: a virada em uma linha + "manda para quem ainda acredita no mito 1".
```

**Cuidado:** não invente um mito só para derrubar.

## IG8: Método para copiar · salvamentos

```
Slide 1: o método {nome} que usamos para {resultado}.
Slides 2..N-1: uma parte do método por slide, com o porquê.
Último slide: o método inteiro em um slide (o que as pessoas salvam) + pedido de salvar.
```

## IG9: Reels que quebra o padrão · compartilhamentos

```
Texto na primeira cena: {afirmação ou pergunta que faz passar reto parecer perder algo}.
Primeira fala: {direto ao ponto, sem "fala, pessoal, tudo bem?"}.
```

## IG10: "Como eu fiz" em Reels · salvamentos

```
Texto na primeira cena: como {resultado com número} em {período}.
Corpo: passo 1, passo 2, passo 3 com legendas na tela, cortes rápidos.
Fim: "salva para fazer junto" + resumo em uma linha na tela.
```

"Como eu fiz" vence "como fazer": resultado em primeira pessoa carrega prova.

| Objetivo | Fórmulas |
|---|---|
| salvamentos | IG1, IG5, IG6, IG8, IG10 |
| compartilhamentos | IG2, IG7, IG9 |
| comentários | IG3, IG4 |
| seguidores | IG4, IG6, IG8 |

## Escolha pela superfície

| Se a ideia é... | Use |
|---|---|
| um resultado, um número, um momento | imagem única + legenda (IG1, IG2, IG3) |
| uma lista de dicas | carrossel IG5 |
| uma transformação com passos | carrossel IG6 |
| uma crença a corrigir | carrossel IG7 |
| um método repetível | carrossel IG8 |
| movimento, demonstração, rosto na câmera | Reels IG9, IG10 |

## Nunca faça

- Esticar uma ideia de uma linha em 10 slides.
- Slide 1 só com título, sem promessa.
- 30 hashtags no começo da legenda.
- Isca de engajamento ("comenta EU QUERO").
- Misturar foto e vídeo no mesmo carrossel.
